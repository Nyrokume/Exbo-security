# EXBO Recovery — исследование восстановления аккаунта

Интерактивная веб-страница о том, как EXBO верифицирует владельцев аккаунтов Stalcraft при восстановлении доступа.

**Сайт:** https://nyrokume.github.io/Exbo-security/

## Описание

Одностраничный отчёт на чистом HTML/CSS/JS: принцип работы отдела игровой безопасности, процедуры поддержки, сводный раздел по факторам верификации и калькулятор с качественной оценкой позиции заявителя.

Все примеры (логины, чеки, IP, журнал активности) **вымышлены** и нужны только для иллюстрации.

## Быстрый старт

Локально:

```bash
# из корня репозитория
start docs/index.html        # Windows
open docs/index.html         # macOS
xdg-open docs/index.html     # Linux
```

Зависимости не требуются.

## Структура репозитория

```
Exbo-security/
├── docs/
│   └── index.html          # вся страница (стили и скрипты inline)
├── .github/workflows/
│   └── pages.yml           # деплой GitHub Pages из docs/
└── README.md
```

## Разделы сайта

| № | ID | Название |
|---|-----|----------|
| 01 | `#section-principle` | Принцип определения владельца |
| 02 | `#section-support-form` | Подача заявки в поддержку |
| 03 | `#section-recommendations` | Рекомендации и апелляция |
| 04 | `#section-verification` | Факторы верификации (API, HWID, чеки, активность, привязки) |
| 05 | `#section-calculator` | Калькулятор оценки позиции |
| 06 | `#section-acknowledgments` | Источники и благодарности |

Внутри §04 — подразделы: вес факторов, HWID, API, ответы API, чеки, история активности, привязки.

## Факторы (качественно)

| Фактор | Приоритет |
|--------|-----------|
| HWID | Критический |
| Сессионный токен | Высокий |
| Хеш пароля | Высокий / средний |
| Bootstrap.jar | Низкий |
| Паттерны трафика | Минимальный |

На сайте **нет публичных процентов** и порогов — калькулятор выдаёт уровни «Высокая / Средняя / Низкая».

## Деплой

При push в `main` workflow **Deploy GitHub Pages** публикует содержимое папки `docs/` на GitHub Pages.

Ручной запуск: Actions → Deploy GitHub Pages → Run workflow.

## Источники

- [unofficial-stalcraft-api](https://github.com/Art3mLapa/unofficial-stalcraft-api) — структура запросов лаунчера
